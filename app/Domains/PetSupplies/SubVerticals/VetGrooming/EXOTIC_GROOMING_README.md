# Exotic Animal Grooming Certification & Safety System

**Версия:** 1.0  
**Дата:** 23.04.2026  
**Модуль:** VetGrooming - Exotic Animal Grooming Certification & Safety

## Обзор

Система обеспечивает безопасный груминг экзотических животных через строгую сертификацию грумеров, обязательные протоколы безопасности и автоматическую блокировку несанкционированных процедур.

### Ключевые особенности

- **Трёхуровневая сертификация** (Certified, Advanced, Master) с жёстким контролем допуска
- **Автоматическая блокировка** записи без нужной сертификации
- **Обязательные протоколы безопасности** для каждого вида животных
- **Мониторинг стресса** и автоматическое уведомление ветеринара при высоких показателях
- **Полная интеграция** с расписанием, медицинской картой и системой безопасности
- **Соответствие 152-ФЗ** и медицинским стандартам РФ

## Классификация экзотических животных

### Группа A (Высокий риск) — Требует Master Exotic Certification

| Вид | Риск | Особенности |
|-----|------|-------------|
| Хорьки | Критический | Сильные укусы, анальные железы, высокая агрессия при стрессе |
| Кролики декоративные (карликовые) | Высокий | Хрупкий скелет, риск стаза ЖКТ, нельзя поднимать за уши |
| Морские свинки | Высокий | Склонность к дерматитам, чувствительная кожа |
| Шиншиллы | Критический | Купание только в песке, хвостовая автотомия у дегу |
| Дегу | Высокий | Хвостовая автотомия, респираторные проблемы |
| Попугаи крупные (ара, какаду, жако) | Критический | Самотравмирование, перегрев, аспирация пыли |
| Игуаны | Критический | Мощные укусы, хвостовая автотомия, температурный режим |
| Хамелеоны | Высокий | Стресс → отказ от еды, сложный температурный режим |
| Бородатые агамы | Высокий | Специфические требования к температуре и влажности |

### Группа B (Средний риск) — Advanced Exotic

| Вид | Риск | Особенности |
|-----|------|-------------|
| Крысы | Средний | Социальные животные, групповой груминг |
| Хомяки | Средний | Ночной образ жизни, склонность к укусам |
| Песчанки | Средний | Пустынные животные, чувствительность к влажности |
| Мелкие птицы (волнистые, кореллы) | Средний | Стресс, перегрев/переохлаждение |
| Черепахи наземные | Средний | Специфический температурный режим |
| Ежи африканские | Высокий | Иглы, переохлаждение, специфическая фиксация |

### Группа C (Базовый уровень) — Certified Exotic

| Вид | Риск | Особенности |
|-----|------|-------------|
| Рептилии мелкие (гекконы) | Средний | Чувствительность к температурному режиму |
| Амфибии (лягушки, аксолотли) | Средний | Кожное дыхание, чувствительность к химии |

## Уровни сертификации грумеров

### Certified Exotic Groomer

**Требования:**
- Завершение базового курса по экзотике
- Практический экзамен (видео)
- Теоретический тест (≥80%)

**Допуск:**
- Группа C (базовый уход)
- Базовый гигиенический груминг Группы B под контролем

### Advanced Exotic Groomer

**Требования:**
- Certified уровень + минимум 6 месяцев опыта
- Завершение продвинутого курса
- Практический экзамен с Группой B
- Теоретический тест (≥85%)

**Допуск:**
- Группа B (полный груминг)
- Безопасная работа с Группой A под контролем Master

### Master Exotic Groomer

**Требования:**
- Advanced уровень + минимум 12 месяцев опыта
- Завершение экспертного курса
- Практический экзамен с Группой A
- Теоретический тест (≥90%)
- Опыт обучения других грумеров

**Допуск:**
- Все группы (полная самостоятельность)
- Обучение других грумеров
- Авторские протоколы
- Работа с агрессивными животными

## Обязательные протоколы безопасности

### Протокол груминга хорьков

**Чек-лист (обязателен перед сеансом):**

- [ ] Проверка анальных желез (обязательно)
- [ ] Оценка запаха и состояния кожи
- [ ] Проверка на наличие паразитов
- [ ] Оценка темперамента (агрессия 1-10)
- [ ] Подготовка полотенца для фиксации
- [ ] Проверка температуры помещения (20-22°C)
- [ ] Подготовка перчаток (обязательно)
- [ ] Наличие аптечки (для укусов)

**Запрещено:**
- Поднимать за шкирку без опыта
- Использовать воду без необходимости
- Игнорировать анальные железы

**Особые риски:**
- Сильные укусы (глубокие раны)
- Анальные железы (неприятный запах, воспаление)
- Стресс → агрессия

### Протокол груминга шиншилл

**Чек-лист:**

- [ ] Проверка состояния шерсти (колтуны)
- [ ] Оценка хвоста (риск автотомии)
- [ ] Проверка дыхания (респираторные проблемы)
- [ ] Подготовка специального песка (никогда вода!)
- [ ] Проверка глаз и ушей
- [ ] Температура помещения (18-22°C)
- [ ] Контроль пыли (респиратор)
- [ ] Нежная фиксация (никакого сильного давления на хвост)

**Запрещено:**
- Купать в воде!
- Тянуть за хвост
- Использовать обычную пыль (только специальный песок)

**Особые риски:**
- Респираторные проблемы от пыли
- Хвостовая автотомия
- Стресс → отказ от еды

### Протокол груминга крупного попугая

**Чек-лист:**

- [ ] Оценка стресса до процедуры (1-10)
- [ ] Подготовка полотенца/специального держателя
- [ ] Проверка температуры помещения (24-26°C)
- [ ] Защита глаз и дыхательных путей
- [ ] Фотографирование маховых перьев до (если wing clip)
- [ ] Проверка состояния клюва
- [ ] Подготовка инструментов (стерильные)
- [ ] Наличие ветеринара на подхвате (для крупных)

**Запрещено:**
- Подрезать маховые перья без опыта
- Игнорировать признаки стресса
- Работать в холодном помещении

**Особые риски:**
- Стресс → самотравмирование
- Повреждение маховых перьев
- Аспирация пыли/пуха
- Перегрев / переохлаждение

### Протокол груминга игуаны

**Чек-лист:**

- [ ] Оценка темперамента (агрессия 1-10)
- [ ] Проверка температуры тела (норма 30-35°C)
- [ ] Подготовка термометра и нагревательного коврика
- [ ] Температура помещения (26-30°C)
- [ ] Влажность (60-80%)
- [ ] Проверка чешуи на повреждения
- [ ] Подготовка перчаток (обязательно)
- [ ] Наличие ветеринара (для крупных)

**Запрещено:**
- Работать без перчаток
- Игнорировать температурный режим
- Дергать за хвост (автотомия)

**Особые риски:**
- Мощные укусы (глубокие раны, инфекции)
- Хвостовая автотомия
- Неправильная температура → иммуносупрессия
- Стресс → отказ от еды

### Протокол груминга крупной собаки с агрессией

**Чек-лист:**

- [ ] Оценка агрессии (1-10)
- [ ] Обязательный намордник или Gentle Leader
- [ ] Двухгрумерная фиксация (агрессия ≥6)
- [ ] Проверка суставов и лап перед стрижкой когтей
- [ ] Контроль температуры (крупные собаки перегреваются)
- [ ] Фотографирование состояния шерсти до
- [ ] Наличие второго грумера (агрессия ≥6)
- [ ] Наличие ветеринара (агрессия ≥8)

**Запрещено:**
- Работать в одиночку с агрессией ≥6
- Игнорировать сигналы агрессии
- Работать без намордника

**Особые риски:**
- Физическая сила и размеры
- Серьёзные укусы и травмы
- Перегрев
- Сложность фиксации

## Использование ExoticGroomingService

### Валидация сертификации

```php
use Modules\VetGrooming\Application\Services\ExoticGroomingService;
use Modules\VetGrooming\Domain\Enums\ExoticCategory;
use Modules\VetGrooming\Domain\Enums\ExoticGroup;

$service = app(ExoticGroomingService::class);

// Проверка сертификации грумера
try {
    $certification = $service->validateGroomerCertification(
        groomerId: 5,
        category: ExoticCategory::BIRDS,
        group: 'group_a'
    );
} catch (InsufficientCertificationException $e) {
    // Грумер не имеет нужной сертификации
    // Получить рекомендуемых грумеров
    $recommended = $service->getRecommendedGroomersForExotic(
        category: ExoticCategory::BIRDS,
        group: ExoticGroup::GROUP_A,
        tenantId: 1
    );
}
```

### Создание сессии груминга

```php
// Птицы/Рептилии
$session = $service->createExoticGroomingSession(
    petId: 1,
    groomerId: 5,
    tenantId: 1,
    exoticType: ExoticCategory::BIRDS,
    speciesGroup: 'large_parrots',
    procedureType: ExoticProcedureType::WING_CLIP,
    stressLevelBefore: 3,
    handlingMethod: HandlingMethod::TOWEL,
    appointmentId: 10
);

// Мелкие млекопитающие
$session = $service->createSmallMammalGroomingSession(
    petId: 2,
    groomerId: 5,
    tenantId: 1,
    mammalGroup: 'ferret',
    procedureType: ExoticProcedureType::MAT_REMOVAL,
    stressLevelBefore: 4,
    handlingMethod: HandlingMethod::TOWEL
);

// Крупные млекопитающие
$session = $service->createLargeMammalGroomingSession(
    petId: 3,
    groomerId: 5,
    tenantId: 1,
    mammalGroup: 'large_dog',
    procedureType: ExoticProcedureType::FULL_GROOM,
    aggressionLevel: 5,
    stressLevelBefore: 3,
    restraintMethod: HandlingMethod::MUZZLE
);
```

### Получение протокола безопасности

```php

// Валидация чек-листа
```

## Автоматизации и уведомления

### Высокий стресс (≥7)

- Автоматическое уведомление владельцу
- Автоматическое уведомление ветеринару
- Рекомендация последующего осмотра
- Запись в медицинскую карту

### Высокая агрессия (≥7)

- Автоматическое уведомление администратору
- Требование второго грумера
- Требование ветеринара (≥8)
- Запись инцидента

### Просроченная сертификация

- Блокировка записи за 30 дней до истечения
- Уведомление грумеру о необходимости переаттестации
- Автоматическое предложение сертифицированных грумеров

## Мониторинг и отчёты

### Ежемесячный отчёт «Экзотический груминг»

- Количество сессий по категориям
- Средний уровень стресса по видам
- Инциденты безопасности
- Просроченные сертификации
- Рекомендации по обучению

### Метрики для Prometheus

- `exotic_grooming_sessions_total{category,species}` — количество сессий
- `exotic_grooming_stress_level{level}` — уровень стресса
- `exotic_grooming_certification_failures_total` — отказы в сертификации
- `exotic_grooming_safety_incidents_total` — инциденты безопасности

- Unit тесты для всех сервисов

## Безопасность и Compliance

### 152-ФЗ соответствие

- Анонимизация медицинских данных
- Шифрование чувствительной информации
- Аудит лог всех действий
- Хранение данных 10 лет

### Безопасность грумеров

- Обязательные протоколы безопасности
- Проверка сертификации перед каждой процедурой
- Автоматическая блокировка несанкционированных действий
- Уведомления о рисках

## Установка и настройка

### 1. Запуск миграций

```bash
php artisan migrate
```

### 2. Конфигурация

Добавьте в `.env`:

```env
# Exotic Grooming Settings
EXOTIC_GROOMING_ENABLED=true
EXOTIC_GROOMING_CERTIFICATION_VALIDITY_DAYS=365
EXOTIC_GROOMING_REMINDERS_ENABLED=true
EXOTIC_GROOMING_STRESS_THRESHOLD=7
EXOTIC_GROOMING_AGGRESSION_THRESHOLD=7
```

Используйте Filament ресурс `ExoticSafetyProtocolResource` для создания протоколов для каждого вида.

### 4. Создание обучающих курсов

Используйте Filament ресурс `ExoticTrainingCourseResource` для создания курсов.
