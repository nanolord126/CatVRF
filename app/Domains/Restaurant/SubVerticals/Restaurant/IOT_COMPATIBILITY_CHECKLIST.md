## Требования к сети

### Минимальные

- **WiFi:** 802.11n (2.4 GHz)
- **Покрытие:** 100% кухни
- **Бандwidth:** 10 Mbps для IoT устройств
- **Latency:** <100ms к MQTT брокеру

### Рекомендуемые

- **WiFi:** 802.11ax (WiFi 6) 2.4/5 GHz
- **Покрытие:** 100% + резервирование
- **Бандwidth:** 50 Mbps для IoT устройств
- **Latency:** <50ms к MQTT брокеру
- **Отдельная VLAN:** Для IoT устройств
- **PoE:** Для питания камер и координаторов

## Безопасность оборудования

### Обязательные меры

1. **Изоляция сети** — отдельная VLAN для IoT
2. **Firewall** — блокировка внешнего доступа к MQTT
3. **VPN** — для удалённого управления
4. **Регулярные обновления** — прошивки Tasmota и Zigbee2MQTT
5. **Сильные пароли** — минимум 16 символов для MQTT

### Рекомендуемые меры

1. **TLS для MQTT** — использование MQTTS
2. **Client Certificates** — мутуальная аутентификация
3. **Physical Security** — ограничение физического доступа
4. **Audit Logging** — запись всех команд устройств
5. **Device Fingerprinting** — контроль MAC-адресов
