# Чек-лист интеграции KDS с маркетплейсом CatVRF

## ✅ Предварительная настройка

### 1. Регистрация модуля
- [ ] Добавить `RestaurantServiceProvider` в `config/app.php`
- [ ] Проверить, что модуль загружается: `php artisan module:list`

### 2. Миграции базы данных
- [ ] Выполнить `php artisan migrate`
- [ ] Проверить создание таблиц:
  - [ ] `kitchen_stations`
  - [ ] `order_kitchen_statuses`
  - [ ] `menu_item_preparation_times`
- [ ] Проверить индексы на таблицах

### 3. Event Listeners
- [ ] Добавить `OrderCreatedListener` в `EventServiceProvider`
- [ ] Добавить `OrderStatusChangedListener` в `EventServiceProvider`
- [ ] Проверить регистрацию: `php artisan event:list`
