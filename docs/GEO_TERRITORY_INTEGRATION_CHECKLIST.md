# Чек-лист применения территориальных правил РФ в модулях CatVRF

Этот документ содержит чек-лист для интеграции централизованной системы географических правил (`GeoTerritoryService`) в различные модули проекта CatVRF.

## Обязательные шаги для каждого модуля

### 1. Определить точки интеграции

- [ ] **Identify territory-sensitive operations** — Какие операции в модуле зависят от территории?
  - Налогообложение
  - Доставка и логистика
  - Валютное регулирование
  - Модерация контента
  - Обработка персональных данных (152-ФЗ)
  - Верификация документов
  - Ценообразование

- [ ] **Identify data sources** — откуда приходит информация о регионе?
  - Формы регистрации
  - Профиль пользователя
  - Адрес доставки
  - IP-геолокация
  - Бизнес-данные (INN, юридический адрес)

### 2. Интеграция GeoTerritoryService

- [ ] **Inject the service** — Добавить `GeoTerritoryService` в конструктор сервиса
  ```php

      private readonly GeoTerritoryService $geoService,

  ```

- [ ] **Add territory check** — Добавить проверку территории перед бизнес-логикой


- [ ] **Use helper functions** — Для простых проверок использовать глобальные хелперы

## Обновление существующего кода

### Поиск мест для интеграции

```bash
# Найти хардкоды стран
grep -r "country.*=.*'RU'" app/
grep -r "country.*=.*'UA'" app/

# Найти хардкоды валют
grep -r "currency.*=.*'RUB'" app/
grep -r "currency.*=.*'USD'" app/

# Найти хардкоды налогов
grep -r "vat.*20" app/
grep -r "tax.*rate" app/
```

### Рефакторинг паттернов

**Паттерн 1: Прямая проверка страны**
```php
// ДО (хардкод)
if ($country === 'RU') {
    // ...
}

// ПОСЛЕ (централизовано)
if (is_russian_territory($regionCode, $country)) {
    // ...
}
```

**Паттерн 2: Определение валюты**
```php
// ДО
$currency = $country === 'RU' ? 'RUB' : 'USD';

// ПОСЛЕ
$currency = is_russian_territory($regionCode, $country) ? 'RUB' : 'USD';
```

**Паттерн 3: Налоговые ставки**
```php
// ДО
$vatRate = $country === 'RU' ? 0.20 : null;

// ПОСЛЕ
$vatRate = is_russian_territory($regionCode, $country) ? 0.20 : null;
```
