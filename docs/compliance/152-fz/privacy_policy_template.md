## 1. Общие положения

1.1. Настоящая Политика обработки персональных данных (далее — Политика) разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» (далее — ФЗ-152) и определяет порядок обработки и защиты персональных данных пользователей медицинской маркетплейса CatVRF.

1.2. Оператор персональных данных — CatVRF LLC, осуществляющий обработку персональных данных на законной и справедливой основе.

1.3. Целью обработки персональных данных является предоставление услуг медицинской маркетплейса, включая бронирование медицинских услуг, консультации с врачами, обработку заказов, верификацию личности, защиту от мошенничества.

## 2. Состав персональных данных

### 2.1. Общие персональные данные
- Фамилия, имя, отчество
- Адрес электронной почты (email)
- Номер телефона
- Адрес доставки
- Дата рождения
- Пол

### 2.2. Специальные категории персональных данных (биометрия)
- Изображение лица (Face ID)
- Биометрические шаблоны лица
- Поведенческие биометрические данные (клавиатурный почерк, движения мыши, жесты)
- Голосовые биометрические данные (при использовании голосовой аутентификации)

### 2.3. Данные для бизнес-верификации (KYB)
- ИНН организации
- ОГРН
- Паспортные данные директора/представителя
- Банковские реквизиты

## 4. Условия обработки персональных данных

4.1. Обработка персональных данных осуществляется с согласия субъекта персональных данных.

4.2. Согласие на обработку персональных данных может быть отозвано субъектом в любое время.

4.3. При отзыве согласия оператор прекращает обработку персональных данных и уничтожает их в срок, не превышающий 30 дней с даты получения отзыва.

4.4. Биометрические персональные данные обрабатываются только при наличии письменного согласия или согласия в форме УКЭП (усиленной квалифицированной электронной подписи).

## 5. Защита персональных данных

### 5.1. Уровень защищённости ИСПДн
Система обработки персональных данных CatVRF соответствует **Уровню 2** согласно Приказу ФСТЭК № 21.

### 5.2. Технические меры защиты
- Шифрование данных при хранении (AES-256-GCM)
- Шифрование данных при передаче (TLS 1.3)
- Колоночное шифрование для чувствительных полей
- Многофакторная аутентификация
- JIT (Just-In-Time) доступ к чувствительным данным
- Аудит всех операций с персональными данными в ClickHouse

### 5.3. Организационные меры защиты
- Назначение ответственного за обработку персональных данных
- Регулярное обучение сотрудников
- Контроль доступа к персональным данным
- План реагирования на инциденты

## 6. Локализация данных

6.1. В соответствии с ч. 5 ст. 18 ФЗ-152, все базы данных, содержащие персональные данные граждан РФ, расположены на территории Российской Федерации.

6.2. Резервные копии также хранятся на территории РФ.

6.3. Трансграничная передача персональных данных не осуществляется без соответствующего разрешения Роскомнадзора.

## 7. Права субъектов персональных данных

7.1. Субъект персональных данных имеет право:
- На доступ к своим персональным данным
- На уточнение (обновление, изменение) своих персональных данных
- На блокировку или уничтожение своих персональных данных
- На отзыв согласия на обработку персональных данных
- На получение информации о том, обрабатываются ли его персональные данные
- На защиту своих прав и законных интересов

7.2. Для реализации прав субъект персональных данных может направить запрос на privacy@catvrf.ru. Ответ предоставляется в течение 10 рабочих дней.

---

## 8. Передача персональных данных третьим лицам

8.1. Персональные данные могут передаваться третьим лицам только:
- С согласия субъекта персональных данных
- По требованию суда, правоохранительных органов
- В целях исполнения договора с субъектом

8.2. Категории получателей персональных данных:
- Медицинские учреждения (для бронирования услуг)
- Платёжные системы (для обработки платежей)
- Курьерские службы (для доставки)
- Врачи (для проведения консультаций)

---

## 9. Уничтожение персональных данных

9.1. Персональные данные уничтожаются:
- После достижения цели обработки
- По истечении срока хранения
- При отзыве согласия субъекта (в течение 30 дней)
- По требованию суда или правоохранительных органов

9.2. Уничтожение персональных данных производится путём физического удаления с последующей перезаписью для зашифрованных данных.

9.3. На каждое уничтожение персональных данных формируется акт уничтожения.
