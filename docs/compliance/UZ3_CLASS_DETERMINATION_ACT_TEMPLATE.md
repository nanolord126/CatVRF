5. **Техническая сложность:** Высокая (multi-tenancy, AI/ML, облачная инфраструктура) — ✓

## 5. РЕЗУЛЬТАТЫ АНАЛИЗА

### 5.1 Класс защиты

**Определенный класс защиты:** УЗ-3

### 5.2 Обоснование

1. **Обработка биометрических ПДн** — требует повышенных мер защиты (ст. 10 152-ФЗ)
2. **Медицинские данные** — регулируются 152-ФЗ и ФЗ-323
3. **Multi-tenancy** — высокий риск cross-tenant leakage (УБИ.225)
4. **AI/ML компоненты** — новые векторы атак (deepfake, behavioral spoofing)
5. **Облачная инфраструктура** — специфические угрозы (УБИ.065, УБИ.226)
6. **Высокий уровень угроз из БДУ** — 8+ критических угроз с CVSS > 7.0
7. **Объем ПДн** — > 100 000 субъектов
8. **Последствия нарушения** — критические (здоровье, финансы, репутация)

### 5.3 Соответствие требованиям

| Требование | Соответствие | Примечание |
|------------|--------------|------------|
| Приказ №21 ФСТЭК | ✓ | Все меры реализованы |
| 152-ФЗ | ✓ | Включая биометрические ПДн |
| ФЗ-323 | ✓ | Медицинские данные |
| Постановление №1119 | ✓ | Класс УЗ-3 обоснован |
