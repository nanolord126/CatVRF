# RealEstate Integration Checklist

## Overview

Этот чек-лист описывает шаги для интеграции модуля RealEstate с маркетплейсом CatVRF и другими системами.

## Prerequisites

- [ ] Установлен модуль RealEstate
- [ ] Создан конфигурационный файл `config/crm-realestate.php`
- [ ] Настроены переменные окружения в `.env`
- [ ] Выполнены миграции базы данных

## Environment Configuration

### Basic Settings
- [ ] `REAL_ESTATE_ENABLED=true` — модуль включён
- [ ] `REAL_ESTATE_CURRENCY=RUB` — валюта установлена
- [ ] `REAL_ESTATE_TIMEZONE=Europe/Moscow` — часовой пояс настроен

### Bookings Configuration
- [ ] `REAL_ESTATE_SLOT_LIFETIME=60` — время жизни слота настроено
- [ ] `REAL_ESTATE_MAX_SLOTS=5` — максимальное количество слотов настроено
- [ ] `REAL_ESTATE_REQUIRE_DEPOSIT=true` — требование депозита включено
- [ ] `REAL_ESTATE_DEPOSIT_PERCENTAGE=10` — процент депозита настроен

### Marketplace Integration
- [ ] `REAL_ESTATE_MARKETPLACE_ENABLED=true` — интеграция с маркетплейсом включена
- [ ] `REAL_ESTATE_SYNC_INTERVAL=15` — интервал синхронизации настроен
- [ ] `REAL_ESTATE_WEBHOOK_SECRET=<secret>` — секретный ключ webhook настроен

### Fraud Detection
- [ ] `REAL_ESTATE_FRAUD_DETECTION_ENABLED=true` — fraud detection включён
- [ ] `REAL_ESTATE_FRAUD_THRESHOLD=0.7` — порог блокировки настроен
- [ ] `REAL_ESTATE_FACE_ID_VERIFICATION=true` — верификация Face ID включена
- [ ] `REAL_ESTATE_BLOCKCHAIN_VERIFICATION=false` — верификация в блокчейне настроена
