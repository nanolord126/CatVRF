# Dental Integration Checklist

## Overview

Этот чек-лист описывает шаги для интеграции модуля Dental с маркетплейсом CatVRF и другими системами.

## Prerequisites

- [ ] Установлен модуль Dental
- [ ] Создан конфигурационный файл `config/crm-dental.php`
- [ ] Настроены переменные окружения в `.env`
- [ ] Выполнены миграции базы данных

## Environment Configuration

### Basic Settings
- [ ] `DENTAL_ENABLED=true` — модуль включён
- [ ] `DENTAL_CURRENCY=RUB` — валюта установлена
- [ ] `DENTAL_TIMEZONE=Europe/Moscow` — часовой пояс настроен

### Treatment Plans Configuration
- [ ] `DENTAL_AUTO_CONFIRM=false` — авто-подтверждение планов лечения настроено
- [ ] `DENTAL_REQUIRE_DEPOSIT=true` — требование депозита настроено
- [ ] `DENTAL_DEPOSIT_PERCENTAGE=30` — процент депозита настроен
- [ ] `DENTAL_HOLD_TIME=60` — время удержания настроено
- [ ] `DENTAL_MAX_PROCEDURES=20` — максимальное количество процедур настроено

### Tooth Charts Configuration
- [ ] `DENTAL_NUMBERING_SYSTEM=fdi` — система нумерации зубов настроена
- [ ] `DENTAL_AUTO_UPDATE_TOOTH_CHART=true` — авто-обновление зубных карт настроено
- [ ] `DENTAL_TRACK_TOOTH_CHANGES=true` — отслеживание изменений настроено

### Marketplace Integration
- [ ] `DENTAL_MARKETPLACE_ENABLED=true` — интеграция с маркетплейсом включена
- [ ] `DENTAL_SYNC_INTERVAL=15` — интервал синхронизации настроен
- [ ] `DENTAL_WEBHOOK_SECRET=<secret>` — секретный ключ webhook настроен

### Fraud Detection
- [ ] `DENTAL_FRAUD_DETECTION_ENABLED=true` — fraud detection включён
- [ ] `DENTAL_FRAUD_THRESHOLD=0.7` — порог блокировки настроен
- [ ] `DENTAL_CHECK_INSURANCE=true` — проверка страховых полисов включена

### Security & Compliance
- [ ] `DENTAL_COMPLIANCE_152_FZ=true` — соответствие 152-ФЗ включено
- [ ] `DENTAL_ENCRYPT_MEDICAL_DATA=true` — шифрование медицинских данных включено
- [ ] `DENTAL_REQUIRE_2FA_MEDICAL=true` — 2FA для медицинских данных включено
