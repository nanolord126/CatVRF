# Auto Integration Checklist

## Overview

Этот чек-лист описывает шаги для интеграции модуля Auto с маркетплейсом CatVRF и другими системами.

## Prerequisites

- [ ] Установлен модуль Auto
- [ ] Создан конфигурационный файл `config/crm-auto.php`
- [ ] Настроены переменные окружения в `.env`
- [ ] Выполнены миграции базы данных

## Environment Configuration

### Basic Settings
- [ ] `AUTO_ENABLED=true` — модуль включён
- [ ] `AUTO_CURRENCY=RUB` — валюта установлена
- [ ] `AUTO_TIMEZONE=Europe/Moscow` — часовой пояс настроен

### Orders Configuration
- [ ] `AUTO_AUTO_CONFIRM=false` — авто-подтверждение заказов настроено
- [ ] `AUTO_REQUIRE_DEPOSIT=true` — требование депозита настроено
- [ ] `AUTO_DEPOSIT_PERCENTAGE=20` — процент депозита настроен
- [ ] `AUTO_HOLD_TIME=30` — время удержания настроено
- [ ] `AUTO_MAX_SERVICES=10` — максимальное количество услуг настроено

### Marketplace Integration
- [ ] `AUTO_MARKETPLACE_ENABLED=true` — интеграция с маркетплейсом включена
- [ ] `AUTO_SYNC_INTERVAL=15` — интервал синхронизации настроен
- [ ] `AUTO_WEBHOOK_SECRET=<secret>` — секретный ключ webhook настроен

### Fraud Detection
- [ ] `AUTO_FRAUD_DETECTION_ENABLED=true` — fraud detection включён
- [ ] `AUTO_FRAUD_THRESHOLD=0.7` — порог блокировки настроен
- [ ] `AUTO_CHECK_VIN=true` — проверка VIN включена
