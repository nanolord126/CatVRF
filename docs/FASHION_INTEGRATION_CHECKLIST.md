# Fashion Integration Checklist

## Overview

Этот чек-лист описывает шаги для интеграции модуля Fashion с маркетплейсом CatVRF и другими системами.

## Prerequisites

- [ ] Установлен модуль Fashion
- [ ] Создан конфигурационный файл `config/crm-fashion.php`
- [ ] Настроены переменные окружения в `.env`
- [ ] Выполнены миграции базы данных

## Environment Configuration

### Basic Settings
- [ ] `FASHION_ENABLED=true` — модуль включён
- [ ] `FASHION_CURRENCY=RUB` — валюта установлена
- [ ] `FASHION_TIMEZONE=Europe/Moscow` — часовой пояс настроен

### Orders Configuration
- [ ] `FASHION_AUTO_CONFIRM=false` — авто-подтверждение заказов настроено
- [ ] `FASHION_REQUIRE_DEPOSIT=false` — требование депозита настроено
- [ ] `FASHION_HOLD_TIME=30` — время удержания настроено
- [ ] `FASHION_MAX_ITEMS=50` — максимальное количество товаров настроено

### Returns Configuration
- [ ] `FASHION_RETURN_PERIOD=30` — период возврата настроен
- [ ] `FASHION_REQUIRE_PACKAGING=true` — требование упаковки настроено
- [ ] `FASHION_REQUIRE_UNWORN=true` — требование не надетого товара настроено
- [ ] `FASHION_AUTO_APPROVE_RETURNS=false` — авто-одобрение возвратов настроено

### Marketplace Integration
- [ ] `FASHION_MARKETPLACE_ENABLED=true` — интеграция с маркетплейсом включена
- [ ] `FASHION_SYNC_INTERVAL=15` — интервал синхронизации настроен
- [ ] `FASHION_WEBHOOK_SECRET=<secret>` — секретный ключ webhook настроен

### Fraud Detection
- [ ] `FASHION_FRAUD_DETECTION_ENABLED=true` — fraud detection включён
- [ ] `FASHION_FRAUD_THRESHOLD=0.7` — порог блокировки настроен
- [ ] `FASHION_MAX_RETURNS_MONTH=3` — максимальное количество возвратов настроено
