## Техническая интеграция

### API Endpoints

- [ ] **Маркетплейс → Flowers**
  - [ ] `POST /api/flowers/webhooks/order-created`
  - [ ] `POST /api/flowers/webhooks/order-cancelled`
  - [ ] `POST /api/flowers/webhooks/payment-confirmed`

- [ ] **Flowers → Маркетплейс**
  - [ ] `POST /api/marketplace/orders/{id}/status`
  - [ ] `POST /api/marketplace/orders/{id}/photo`
  - [ ] `GET /api/marketplace/venues/{id}/availability`

### Конфигурация

- [ ] **Environment Variables**
  ```env
  FLOWERS_MARKETPLACE_ENABLED=true
  FLOWERS_MARKETPLACE_API_KEY=your_api_key
  FLOWERS_MARKETPLACE_WEBHOOK_SECRET=your_secret
  FLOWERS_MARKETPLACE_COMMISSION=5.0
  
  FLOWERS_KDS_ENABLED=true
  FLOWERS_KDS_WEBSOCKET_URL=wss://kds.catvrf.ru
  ```

- [ ] **Config Settings**
  - [ ] Настройка webhook URL
  - [ ] Настройка retry политики
  - [ ] Настройка timeout для API запросов
  - [ ] Настройка очередей для async операций

### Очереди (Queues)

- [ ] **Job Queue**
  - [ ] `flowers:marketplace-sync` — синхронизация с маркетплейсом
  - [ ] `flowers:status-update` — обновление статусов
  - [ ] `flowers:notification` — отправка уведомлений
  - [ ] `flowers:freshness-check` — проверка свежести
